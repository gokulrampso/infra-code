# Infra Code Repository

This repository contains infrastructure-as-code (IaC) and GitOps configurations for the platform. It is structured to support Kubernetes, ArgoCD, monitoring (Grafana, Prometheus, ELK), Istio, Terraform, and Ansible.

## Structure

- `k8s/` - Kubernetes manifests and Helm charts
- `argocd/` - ArgoCD application definitions
- `monitoring/` - Monitoring stack (Grafana, Prometheus, ELK)
- `istio/` - Istio service mesh configuration
- `terraform/` - Terraform IaC modules and environments
- `ansible/` - Ansible playbooks and roles

Each directory contains a README with more details and usage instructions.
